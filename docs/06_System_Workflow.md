### 1. วัตถุประสงค์
เอกสารฉบับนี้อธิบายขั้นตอนการทำงาน (Workflow) และลำดับเหตุการณ์ (Sequence of Events) ของระบบ "ลาดพร้าวสร้างสุข" เพื่อให้ทีมพัฒนาเห็นภาพรวมของการไหลของข้อมูล (Data Flow) และกระบวนการดำเนินงานของแต่ละโมดูลหลัก

--------------------------------------------------------------------------------

### 2. ขั้นตอนการลงทะเบียน (Registration Workflow)
ระบบใช้กระบวนการลงทะเบียน 5 ขั้นตอนเพื่อความสมบูรณ์ของข้อมูล:
1.  **ขั้นตอนที่ 1 ข้อมูลส่วนตัว:** ผู้ใช้กรอกข้อมูลพื้นฐาน ตำแหน่ง และฝ่ายสังกัด
2.  **ขั้นตอนที่ 2 ข้อมูลสุขภาพ:** กรอกน้ำหนัก ส่วนสูง และรอบเอว ระบบคำนวณ BMI อัตโนมัติ
3.  **ขั้นตอนที่ 3 เลือกกิจกรรม:** เลือกกิจกรรมสุขภาวะที่สนใจเข้าร่วม (บังคับเลือกกิจกรรมงดน้ำหวาน)
4.  **ขั้นตอนที่ 4 ตั้งรหัสผ่าน:** กำหนดรหัสผ่านสำหรับการเข้าใช้งานครั้งถัดไป
5.  **ขั้นตอนที่ 5 ยืนยันข้อมูล:** ตรวจสอบความถูกต้องและบันทึกลง Google Sheets ผ่าน GAS API

--------------------------------------------------------------------------------

### 3. ขั้นตอนการบันทึกก้าวเดิน (Step Logging Workflow)
ผู้ใช้สามารถบันทึกจำนวนก้าวได้ 2 รูปแบบ:
*   **แบบที่ 1: Google Fit Sync (อัตโนมัติ)**
    1. ผู้ใช้กดเชื่อมต่อ Google Fit
    2. ระบบดึงข้อมูลก้าวเดินผ่าน API และบันทึกเข้า Google Sheets โดยที่ผู้ใช้ไม่สามารถแก้ไขตัวเลขได้
*   **แบบที่ 2: อัปโหลดภาพ (AI OCR)**
    1. ผู้ใช้อัปโหลดภาพแคปหน้าจอผลการนับก้าวจากแอปอื่น
    2. ระบบส่งภาพไปเก็บที่ Google Drive และใช้ **Gemini OCR** สกัดตัวเลขก้าวเดิน
    3. ข้อมูลอยู่ในสถานะ "รอตรวจสอบ (Pending)"
    4. ผู้ดูแลระบบ (นสส.) ตรวจสอบความถูกต้องและกดอนุมัติ (Approved) ข้อมูลจึงจะแสดงผลใน Dashboard

--------------------------------------------------------------------------------

### 4. ขั้นตอนกิจกรรม "พุธนี้ไม่มีเชื่อม" (Sweet-Free Wednesday Workflow)
เป็นกิจกรรมที่เน้นการบริหารจัดการโดยเจ้าหน้าที่:
1.  ทุกวันพุธ เจ้าหน้าที่ นสส. สังเกตพฤติกรรมหรือรับแจ้งการงดน้ำหวานของบุคลากร
2.  เจ้าหน้าที่เข้าสู่ระบบหน้า Admin และบันทึกสถานะ (🟢 งดได้ / 🔴 งดไม่ได้) รายฝ่าย
3.  ระบบประมวลผลและแสดงสถานะบน Dashboard ส่วนบุคคลและ Leaderboard ระดับฝ่ายทันที

--------------------------------------------------------------------------------

### 5. ขั้นตอนกิจกรรม Happy Connect (Cross-Department Matching)
ระบบส่งเสริมความสัมพันธ์ต่างฝ่ายผ่านการสุ่มคู่:
1.  **การจับคู่:** ทุกเช้าวันจันทร์ ระบบสุ่มจับคู่บุคลากรที่สังกัด "คนละฝ่าย"
2.  **การแจ้งเตือน:** ระบบแสดง Pop-up เมื่อเข้าเว็บ และส่งแจ้งเตือนผ่าน LINE OA
3.  **การปฏิบัติภารกิจ:** คู่ Buddy ทำกิจกรรมร่วมกัน (เช่น จิบกาแฟ, เดินร่วมกัน) และถ่ายรูปคู่
4.  **การยืนยัน:** ทั้งสองฝ่ายอัปโหลดรูปและกดยืนยันในระบบ เพื่อรับคะแนนสะสมและ Badge

--------------------------------------------------------------------------------

### 6. ขั้นตอนการจัดการอบรม (Training Workflow)
1.  **สร้างหลักสูตร:** ผู้ดูแลระบบสร้างหัวข้ออบรม กำหนดวัน เวลา สถานที่ และจำนวนที่นั่ง
2.  **รับสมัคร:** สมาชิกเข้าสู่ระบบเพื่อเลือกรอบการอบรมที่ว่างอยู่
3.  **เช็กชื่อ:** เมื่อถึงวันอบรม ผู้ดูแลระบบเช็กชื่อผู้เข้าเรียนผ่านระบบ
4.  **ออกรายงาน:** ระบบสรุปรายชื่อและผลการอบรมเพื่อจัดทำรายงานประจำเดือน

--------------------------------------------------------------------------------

### 7. ขั้นตอนการประมวลผลรายงาน (Reporting Workflow)
1.  ระบบรวบรวมข้อมูลดิบจาก Google Sheets ทุกโมดูล
2.  **Dashboard:** ประมวลผลข้อมูล Real-time แสดงผลเป็นกราฟและสถิติผ่านหน้าเว็บ
3.  **Official Report:** เมื่อผู้บริหารหรือนสส. ต้องการรายงาน ระบบจะแปลงข้อมูลเป็นรูปแบบเอกสารราชการภาษาไทย (PDF A4)
