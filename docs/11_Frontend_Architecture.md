### 1. วัตถุประสงค์
เอกสารฉบับนี้กำหนดโครงสร้างสถาปัตยกรรมส่วนหน้าบ้าน (Frontend Architecture) ของเว็บแอปพลิเคชัน "ลาดพร้าวสร้างสุข" เพื่อเป็นมาตรฐานให้ทีมพัฒนาใช้ในการเจนเนอเรตโค้ดผ่าน **OpenCode** และเครื่องมือ AI โดยเน้นประสิทธิภาพการทำงาน ความปลอดภัย และประสบการณ์ผู้ใช้งานที่ลื่นไหลตามมาตรฐานสากล

--------------------------------------------------------------------------------

### 2. เทคโนโลยีหลัก (Tech Stack)
ระบบถูกพัฒนาบนพื้นฐานของเทคโนโลยี Modern Web ดังนี้:
*   **Core Framework:** **Next.js (App Router)** เพื่อประสิทธิภาพการทำ Routing และ Server Components
*   **Base Library:** **React** และ **TypeScript** เพื่อความแม่นยำของข้อมูลและ Type Safety
*   **UI Toolkit:** **Tailwind CSS** และ **DaisyUI** สำหรับการสร้างอินเทอร์เฟซที่รวดเร็วและสวยงาม
*   **Deployment:** **GitHub** เชื่อมต่อกับ **Vercel** สำหรับการทำ CI/CD และ Hosting

--------------------------------------------------------------------------------

### 3. โครงสร้างโฟลเดอร์ (Directory Structure)
เพื่อให้การจัดการโค้ดเป็นระบบและง่ายต่อการขยายผลในอนาคต โครงสร้างไฟล์ในโฟลเดอร์ `/src` จะเป็นดังนี้:

```text
/src
  /app                  # โครงสร้าง Routing ตาม App Router
    /register           # โมดูลลงทะเบียน 5 ขั้นตอน
    /dashboard          # หน้าสถิติและภาพรวม
    /steps              # ระบบบันทึกก้าวและประวัติ
    /wellness           # ศูนย์รวมความสุข (Wellness Hub)
    /admin              # ส่วนจัดการของผู้ดูแลระบบ (นสส.)
  /components           # ส่วนประกอบ UI ที่ใช้ซ้ำได้
    /layout             # Sidebar (Left), TopBar, Drawer
    /ui                 # GlassCard, Button, StatusBadge
    /modules            # Component เฉพาะแต่ละฟีเจอร์
  /hooks                # Custom Hooks สำหรับ Business Logic
  /services             # API Functions เชื่อมต่อกับ GAS REST API
  /utils                # ตัวช่วยคำนวณ (BMI) และฟอร์แมตวันที่ไทย (พ.ศ.)
  /types                # TypeScript Interfaces ของ Domain Model
```

--------------------------------------------------------------------------------

### 4. การจัดการสถานะและการเชื่อมต่อข้อมูล (State & Data Management)
*   **Data Fetching:** ใช้ **Fetch API** ในการเชื่อมต่อกับ **Google Apps Script (GAS) Web App** ซึ่งทำหน้าที่เป็น REST API หลังบ้าน
*   **State Management:** ใช้ **React Context API** หรือ **Zustand** ในการเก็บสถานะการเข้าสู่ระบบ (Session) และข้อมูลโปรไฟล์เบื้องต้น
*   **Real-time Updates:** แสดงผลข้อมูลบน Dashboard แบบทันสมัย และมีสถานะ Loading (Skeleton Screen) ระหว่างรอข้อมูลจาก API

--------------------------------------------------------------------------------

### 5. มาตรฐานการออกแบบอินเทอร์เฟซ (UI/UX Standards)
*   **Design Concept:** เน้นสไตล์ **"Futuristic Clean"** ที่ล้ำสมัยแต่ดูสะอาดตา
*   **Visual Elements:** ใช้เทคนิค **Glassmorphism** (พื้นหลังโปร่งแสง), มุมโค้งมนระดับ `rounded-2xl` และเอฟเฟกต์ **Soft Glow**
*   **Localization:**
    *   ส่วนติดต่อผู้ใช้งานเป็น **ภาษาไทย 100%**
    *   การแสดงผลวันที่ต้องใช้รูปแบบ **ปี พ.ศ. แบบเต็ม**
*   **Navigation:** แถบเมนูหลักอยู่ทาง **ซ้ายของหน้าจอ (Left Sidebar)** บน Desktop และเป็น **Left Drawer** บน Mobile

--------------------------------------------------------------------------------

### 6. การตอบสนองและการแสดงผล (Responsive Design)
*   **Mobile First:** ออกแบบให้ใช้งานบนมือถือได้อย่างดีเยี่ยม (บันทึกก้าว/งดหวาน) และขยายผลไปยัง Tablet และ Desktop
*   **Adaptive Layout:** ปรับเปลี่ยนการจัดวางตามขนาดหน้าจอโดยอัตโนมัติผ่าน Tailwind Responsive Breakpoints

--------------------------------------------------------------------------------

### 7. การเชื่อมต่อระบบภายนอก (External Integration)
*   **Google Fit:** เชื่อมต่อผ่าน OAuth2 เพื่อดึงข้อมูลสุขภาพโดยตรง
*   **Gemini AI OCR:** ส่งภาพถ่ายหลักฐานนับก้าวไปยัง AI เพื่อสกัดตัวเลขจำนวนก้าว
*   **LINE OA:** รับส่งข้อมูลผ่าน Messaging API เพื่อแจ้งเตือนบุคลากร
