### [1.0.0] - 2569-07-26
#### Added (สิ่งที่เพิ่มเข้ามา)
*   **โครงสร้างเอกสารโครงการ (Project Documentation):** จัดทำชุดเอกสารมาตรฐานรวม 27 ไฟล์ เพื่อเป็นแหล่งข้อมูลหลัก (Single Source of Truth) ในการพัฒนาระบบ
*   **นิยามขอบเขตและเป้าหมาย:** กำหนดพันธกิจ "สร้างองค์กรแห่งความสุข" และเป้าหมาย 4 ด้าน (Happy Body, Mind, Relationship, Organization)
*   **การออกแบบสถาปัตยกรรม (System Architecture):** กำหนดการใช้ Next.js (Frontend), Google Apps Script (Backend), Google Sheets (Database) และ Google Drive (Storage)
*   **ข้อกำหนดเชิงหน้าที่ (Functional Requirements):** กำหนด 10 โมดูลหลัก เช่น ระบบนับก้าว (OCR/Google Fit), กิจกรรมงดน้ำหวาน, ระบบอบรมออฟฟิศซินโดรม และระบบสุ่มคู่บัดดี้ต่างฝ่าย
*   **มาตรฐาน UI/UX:** กำหนดธีม "Futuristic Clean", การใช้ภาษาไทย 100%, รูปแบบวันที่ พ.ศ. และระบบเมนูแบบ Left Sidebar Navigation
*   **การจัดการข้อมูลและความปลอดภัย:** กำหนดโครงสร้าง Google Sheet Schema, ระบบสิทธิ์การใช้งาน (RBAC) และมาตรฐานการคุ้มครองข้อมูลส่วนบุคคล (PDPA)
*   **Master Prompt:** จัดทำคำสั่งหลักสำหรับสั่งการ AI Agent (OpenCode/AI Studio) เพื่อให้เจนเนอเรตโค้ดได้ตรงตามข้อกำหนดทุกประการ

#### Changed (สิ่งที่เปลี่ยนแปลง)
*   **สถาปัตยกรรมฐานข้อมูล:** ปรับเปลี่ยนจากการใช้ Firebase เป็น Google Sheets ทั้งหมดเพื่อลดค่าใช้จ่ายและง่ายต่อการดูแลรักษาโดยเจ้าหน้าที่
*   **โครงสร้างเมนู:** ปรับปรุงจากเมนูทั่วไปเป็นระบบ Left Sidebar สำหรับ Desktop และ Left Drawer สำหรับ Mobile เพื่อเพิ่มพื้นที่การทำงาน
*   **โมดูล Happy Connect:** เพิ่มระบบ Welcome Engagement Popup และภารกิจกระชับความสัมพันธ์ประจำสัปดาห์ (Buddy Missions)

#### Security (ความปลอดภัย)
*   **Secrets Management:** กำหนดห้ามเก็บ API Key และ Secret ไว้ในซอร์สโค้ด โดยให้ย้ายไปที่ Environment Variables ของ Vercel เท่านั้น
*   **Audit Log:** เพิ่มข้อกำหนดการบันทึกประวัติการกระทำของผู้ดูแลระบบในทุกโมดูลสำคัญ
